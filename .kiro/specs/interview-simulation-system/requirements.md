# 面试模拟系统 - 需求文档

## 简介

面试模拟系统是一套面向求职者的 AI 辅助面试练习平台。用户可以根据目标岗位、面试难度、工作经验等信息，由 AI（DeepSeek）自动生成面试题目，模拟真实面试流程（一面/二面/三面），并提供实时点评与面试报告。系统还配备知识社区，支持 AI 获取岗位相关知识文章，帮助用户系统性备考。

## 术语表

| 术语 | 说明 |
|------|------|
| 面试者 | 注册并使用本系统进行模拟面试的用户 |
| 岗位 | 面试目标职位，如后端开发、前端开发、大数据、AI、会计等 |
| 面试轮次 | 一面（基础）、二面（技术深度）、三面（综合/HR） |
| 难度 | 初级、中级、高级 |
| 经验年限 | 应届生、1-3年、3-5年、5年以上 |
| DeepSeek | 第三方 AI 接口，用于生成题目、点评答案、获取知识 |
| 面试报告 | 一次模拟面试结束后 AI 生成的综合评价 |

---

## 技术栈与目录结构

- 前端：Vue2 + ElementUI，目录 `ui/`
- 后端：Gin + GORM，RESTful API，目录 `api/`
- 缓存：Redis（用户信息永久存储）
- AI：DeepSeek API

### 环境变量

```
DEEPSEEK_API_KEY=your_deepseek_api_key_here
REDIS_HOST=172.19.31.128
REDIS_PORT=6379
REDIS_DB=1
```

## 需求一：用户注册与登录

**用户故事：** 作为一名求职者，我希望能注册账号并登录系统，以便使用面试模拟功能。

### 验收标准

1. 系统提供注册页面，需填写：用户名、手机号/邮箱、密码、确认密码。
2. 注册时对手机号/邮箱格式进行校验，密码不少于 8 位。
3. 注册成功后，用户信息永久保存在 Redis 中（无过期时间）。
4. 系统提供登录页面，支持用户名或手机号/邮箱 + 密码登录。
5. 登录成功后颁发 JWT Token，前端存储于 localStorage。
6. Token 有效期为 7 天，到期后需重新登录。
7. 提供「忘记密码」入口（预留，后续实现）。
8. 登录失败时提示具体原因（账号不存在 / 密码错误）。
9. WHEN 用户已登录时访问注册/登录页，THEN 自动跳转至首页仪表盘。

### 访问控制（未登录态）

10. 系统默认进入登录页，未登录用户无法访问任何功能页面。
11. 未登录时，顶部导航栏**仅显示 Logo 和「登录/注册」按钮**，所有功能链接（首页、面试中心、题库、社区）全部隐藏。
12. 未登录时，二级导航栏完全隐藏。
13. WHEN 未登录用户直接访问任意功能页（仪表盘、面试配置、题库、社区、个人中心等），THEN 系统自动重定向至登录页。
14. 登录成功后，导航栏展示完整功能入口，并跳转至首页仪表盘（或登录前尝试访问的目标页）。

## 需求二：面试配置

**用户故事：** 作为面试者，我希望在发起模拟面试前配置岗位、难度、经验等信息，以便系统生成匹配的面试题目。

### 验收标准

1. 系统提供面试配置页面，包含以下选项：
   - **目标岗位**（下拉单选）：后端开发、前端开发、大数据工程师、AI算法工程师、会计/财务、产品经理、测试工程师、运维工程师、移动端开发（可扩展）
   - **面试难度**（单选）：初级、中级、高级
   - **工作经验**（单选）：应届生、1-3年、3-5年、5年以上
   - **面试轮次**（单选）：一面、二面、三面
   - **重点方向**（多选标签，可选）：算法、系统设计、项目经验、基础知识、场景题
2. 所有必填项（岗位、难度、经验、轮次）未填写时，提交按钮置灰并提示。
3. 配置完成后点击「发起面试」，系统记录本次面试配置并调用 AI 生成题目。
4. WHEN 用户提交配置，THEN 系统在后台调用 DeepSeek API，生成对应题目集合（异步，前端展示加载状态）。
5. 题目生成完成后，自动跳转至面试答题页面。
6. 系统保存用户每次的面试配置，可在「我的面试记录」中查看历史配置。

## 需求三：AI 面试题目生成

**用户故事：** 作为面试者，我希望系统根据我的配置自动生成面试题，使每次练习都贴近真实面试场景。

### 验收标准

1. 系统调用 DeepSeek API，根据岗位 + 难度 + 经验年限 + 面试轮次生成题目集合。
2. 不同轮次的题目构成：
   - **一面**：自我介绍（必含）+ 基础知识题（60%）+ 简单算法/逻辑题（20%）+ 项目经历简述（20%）
   - **二面**：技术深度题（50%）+ 系统设计题（30%）+ 项目经验追问（20%）
   - **三面**：综合能力题（40%）+ 职业规划（30%）+ HR 类问题（30%）
3. 题目数量：每次面试默认生成 8-12 道题（可配置）。
4. 每道题目包含：题目内容、知识点标签、参考难度、预计作答时间。
5. IF 调用 DeepSeek 失败，THEN 系统提示用户并提供重试按钮，同时支持从本地题库降级。
6. 题目生成后缓存到 Redis，有效期 24 小时，同一配置重复发起时优先使用缓存。

## 需求四：面试模拟答题

**用户故事：** 作为面试者，我希望能逐题作答并获得 AI 实时点评，以便了解自己的答题质量。

### 验收标准

1. 答题页面按题目顺序逐题展示，每次只显示一道题目。
2. 每道题目显示：题目编号、题目内容、知识点标签、预计作答时间（倒计时）。
3. 用户通过文本输入框填写答案，支持 Markdown 格式（代码块等）。
4. 用户提交单题答案后，系统调用 DeepSeek 对该答案进行点评：
   - 答案得分（0-100）
   - 优点分析
   - 不足之处
   - 参考答案（折叠展示，用户可点击查看）
5. 用户可选择「跳过」当前题目，跳过的题目在报告中标记为未作答。
6. 面试过程中顶部展示进度条（已完成题数 / 总题数）。
7. WHEN 所有题目作答完成，THEN 系统自动跳转至面试报告页面。
8. 答题过程中支持「暂停面试」，下次登录可继续（数据保存在 Redis，7天有效）。

## 需求五：面试结果与评分报告

**用户故事：** 作为面试者，我希望面试结束后能立即看到是否通过、综合评分、每道题的详细得分和题目内容，以便全面了解自己的表现并针对性改进。

### 验收标准

#### 5.1 面试通过结果判定

1. WHEN 所有题目作答完毕（或超时），THEN 系统自动跳转至「面试结果」页面。
2. 系统根据综合得分给出明确的面试结论：
   - **通过**（综合得分 ≥ 75）：显示绿色「✅ 恭喜，模拟面试通过！」
   - **待定**（综合得分 60-74）：显示橙色「⚠️ 发挥一般，建议加强练习」
   - **未通过**（综合得分 < 60）：显示红色「❌ 本次未通过，继续努力！」
3. 结果页顶部突出展示通过/未通过状态（大字体 + 颜色徽章），让用户第一眼即可获知结论。
4. IF 用户跳过题目超过总题数的 50%，THEN 系统自动判定为「未通过」，并提示「跳过题目过多」。

#### 5.2 综合评分

1. 综合得分 = 所有已作答题目得分的加权平均（跳过题目计 0 分）。
2. 评分等级对照：
   | 分数段 | 等级 | 含义 |
   |--------|------|------|
   | 90-100 | 优秀 ⭐⭐⭐ | 表现出色，达到该岗位高级水准 |
   | 75-89  | 良好 ⭐⭐  | 基本达标，具备上岗能力 |
   | 60-74  | 及格 ⭐   | 有一定基础，仍需加强 |
   | 0-59   | 待提升 | 建议系统性补充知识 |
3. 报告顶部以大号数字 + 圆形仪表盘样式展示综合得分。
4. 同时展示本次面试的基本信息：岗位、轮次、难度、用时、作答题数/总题数。

#### 5.3 评分明细（逐题展示）

1. 报告中完整还原每一道面试题目，包含：
   - 题目编号与题目完整内容
   - 知识点标签、难度标签
   - **用户作答内容**（完整展示，支持 Markdown 渲染）
   - **AI 评分**（0-100，进度条可视化）
   - **AI 点评**：优点、不足（分条列出）
   - **参考答案**（折叠展示，点击展开）
2. 跳过的题目也在列表中展示，标记为「已跳过 - 0分」，同样附上参考答案供学习。
3. 每道题目的评分进度条颜色区分：
   - 80-100 分：绿色
   - 60-79 分：橙色
   - 0-59 分：红色
4. 题目列表支持筛选：全部 / 已作答 / 已跳过 / 高分题 / 低分题。

#### 5.4 知识点模块得分

1. 按知识点分类汇总得分，以雷达图展示（如：算法、数据库、网络、框架原理、系统设计）。
2. 每个知识点模块展示：模块名、该模块题目数、平均得分、强弱评估。

#### 5.5 AI 综合评价与建议

1. AI 生成整体优势总结（不少于 3 条）。
2. AI 生成主要不足与具体改进建议（不少于 3 条，每条建议附带推荐学习资源链接）。
3. AI 给出针对该岗位下一步备考路线图（文字描述）。

#### 5.6 报告持久化与分享

1. 报告永久保存至 Redis，key 格式：`report:{userId}:{interviewId}`。
2. 可在「我的面试历史」中随时回看完整报告（包含题目和作答内容）。
3. 报告支持生成分享链接，链接 7 天有效，分享页仅展示得分和评语（隐藏作答内容）。
4. 报告支持导出 PDF（预留接口，后续实现）。

## 需求六：题库管理

**用户故事：** 作为面试者，我希望能浏览系统题库，按岗位和知识点自主练习。

### 验收标准

1. 题库页面支持多维度筛选：岗位类别、难度等级、知识点标签、题目类型（基础/算法/设计/HR）。
2. 题目列表分页展示，每页 20 条，支持关键词搜索。
3. 每道题目展示：标题、岗位标签、难度、知识点、作答人数、平均得分。
4. 用户点击题目可进入单题练习模式，获得 AI 点评。
5. 用户可对题目进行收藏，收藏题目在个人中心「我的收藏」中查看。
6. WHEN 管理员（系统角色）时，THEN 支持手动添加/编辑/删除题目。
7. 题目数据优先从 Redis 缓存读取，缓存未命中则通过 DeepSeek 动态生成并写入缓存。

## 需求七：知识社区

**用户故事：** 作为面试者，我希望通过 AI 获取与目标岗位相关的知识文章，帮助我系统性备考。

### 验收标准

1. 社区首页展示按岗位分类的知识专区（后端/前端/大数据/AI/会计/通用）。
2. 用户可在对应专区发起「AI 知识获取」请求，输入想了解的知识点，系统调用 DeepSeek 生成文章。
3. AI 生成的文章包含：标题、正文（支持 Markdown）、知识点标签、相关题目推荐。
4. 社区文章支持：浏览、点赞、收藏、评论（评论为用户手动输入，不经 AI 生成）。
5. 文章列表按热度（点赞+收藏+评论数）和时间排序，支持切换。
6. WHEN 用户评论时，THEN 系统对评论内容进行基础敏感词过滤。
7. 每个用户每天通过 AI 生成文章的次数限制为 10 次（防止滥用，配置在环境变量）。

## 需求八：个人中心

**用户故事：** 作为面试者，我希望在个人中心查看我的面试历史、成长数据和收藏内容。

### 验收标准

1. 个人信息页：支持修改头像、昵称、个人简介，密码修改需验证旧密码。
2. 面试历史：列表展示所有历史面试记录（时间、岗位、得分、轮次），支持查看对应报告。
3. 成长轨迹：图表展示近 30 次面试的得分变化趋势。
4. 我的收藏：分标签展示收藏的题目和收藏的文章。
5. 统计数据：展示累计面试次数、平均得分、最高得分、最常练习的岗位。

## 正确性属性（用于属性测试）

1. **用户唯一性**：系统中不存在两个相同手机号/邮箱的账号。
2. **Token 安全性**：过期的 JWT Token 不能访问任何受保护接口。
3. **题目生成一致性**：相同的（岗位 + 难度 + 经验 + 轮次）配置，在缓存有效期内返回相同的题目集合。
4. **得分合法性**：每道题目的 AI 评分始终在 0-100 范围内。
5. **报告完整性**：面试报告中的题目数量与作答阶段题目数量一致（跳过题目标记为未作答，不丢失）。
6. **AI 调用限流**：单用户每天 AI 知识文章生成次数不超过配置上限，超出后返回 429 错误。
7. **Redis 持久化**：用户信息写入 Redis 时使用无过期时间（PERSIST），重启后数据不丢失。
8. **导航可见性**：未登录状态下，顶部导航栏中不存在任何指向功能页面的可点击链接（Logo 和登录按钮除外）。
